Privacy

What this site records when you visit, and how long it keeps it.

The server log

Every request that reaches our server goes into its access log with:

  • your IP address
  • the date and time
  • the address you asked for
  • the page that linked you here, if your browser sends it
  • your browser's user agent string

A request that fails can also go into the error log, with your IP address, the address you asked for and the page that linked you there.

The access log is deleted after at most 15 days. The error log is cleared out the same way, but only on days that had errors, so its entries can stay longer. We open the logs only to look into problems with the site. We run no analytics on them, and we do not share or sell them.

An open page checks in

While the main page is open, it asks the server for the latest block every 3 to 4 seconds so it can reload when a block is found, and it reloads anyway after 10 minutes without one. When it opens, and every 5 minutes after that, it also fetches itself again to warn you if what you are reading is out of date. Each of those requests is logged with your IP address when it reaches our server.

Cloudflare

Requests to reorg.watch go through Cloudflare first. Cloudflare:

  • sees your IP address and what you asked for
  • adds its Web Analytics script to every page; the script loads from static.cloudflareinsights.com and reports which page you opened, the page that linked you there, your browser and operating system, how long the page took to load, and how quickly it responded when you clicked or typed, including which part of the page you used
  • asks your browser to report requests that fail
  • can set its own cookies, for example when it checks whether a visitor is a bot
  • shows us some of what it records in its dashboard, which can include IP addresses

Cloudflare's privacy policy covers what it keeps.

Everything else

  • This site sets no cookies, and its own code runs no analytics. It has no accounts or ads.
  • Apart from Cloudflare's analytics script, every script and image comes from reorg.watch.
  • Your browser remembers which window the Pool share tab shows, the default or the one you picked. It is not sent to us.
  • Links to other sites leave this one, and those sites have their own policies. Your browser tells them only that you came from reorg.watch, not which page.

Questions

Open an issue on the site's GitHub repository, where the source of the page generator also lives. If the logging changes, this page changes with it.
